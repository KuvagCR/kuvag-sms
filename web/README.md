# Webové rozhraní

Plánovaná lokální desktopová aplikace. Zatím zde není připojení k OneDrivu ani funkce odesílání SMS.

Požadované obrazovky:
- přehled a stav připojení telefonu,
- načtení zaměstnanců pouze pro čtení,
- výběr všech / středisek / jednotlivých osob,
- náhled zprávy a příjemců,
- potvrzení rozesílky,
- lokální historie.

Veškeré odesílání musí být blokováno, dokud nebude ověřena SIM 2.
